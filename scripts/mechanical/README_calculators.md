# 🔧 Mechanical Calculators (12 tools)

12 Python calculators for mechanical engineering:

| Tool | Purpose |
|------|---------|
| `sw_beam_calculator.py` | Beam: deflection, bending stress, shear, MAWP |
| `sw_gear_calculator.py` | Gears: spur/helical/bevel/worm (ISO 6336, AGMA 2001) |
| `sw_shaft_calculator.py` | Shaft: torsion, bending, fatigue, critical speed (ASME B106.1M, DIN 743) |
| `sw_tolerance_stack.py` | Tolerance stack-up: worst-case, RSS, Monte Carlo (ASME Y14.5, ISO 1101) |
| `sw_spring_design.py` | Springs: compression/extension/torsion (EN 13906, DIN 2088/2089) |
| `sw_press_fit.py` | Press-fit: force, stress, slip (DIN 18095) |
| `sw_bolt_pattern.py` | Bolt pattern: tensile force, moment, prying, safety factor |

Each calculator has its own `README_<name>.md` with detailed instructions.
